COMMON QUESTIONS

answered.

Need more details? Check the documentation or ask the community ↗.

Is AlphaCode actually free?+

Yes. The application is MIT-licensed and includes a free AI provider. Third-party paid models are optional.

Can I use my existing AI model?+

Yes. AlphaCode supports multiple providers, including Claude, GPT, Gemini, Ollama and compatible endpoints. Available integrations depend on the release.

Does AlphaCode only suggest code?+

No. It can inspect projects, edit files, execute supported tools and tests, and assist with browser and desktop workflows. Review actions and results before shipping.

Which operating systems are supported?+

Windows, macOS and Linux. The installation guide includes platform-specific commands.

How do I stay in control?+

Review edits, tool outputs and tests. Use appropriate permissions, back up important work and evaluate any risky actions.
