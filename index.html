06 / GOOD QUESTIONS

The details,
made simple.

Have a question we haven't covered? Ask the community ↗

Is AlphaCode really free? +

Yes. AlphaCode is MIT-licensed and includes a free AI provider, so you can get started without entering an API key. Optional paid model providers are separate.

Can I use my existing AI model? +

Yes. AlphaCode supports multiple providers, including Claude, GPT, Gemini, Ollama and OpenAI-compatible endpoints. The available integrations vary by release.

Does it only suggest code? +

No. AlphaCode can inspect your project, edit files, run commands and tests, automate supported browser and desktop workflows, and report results for your review.

What operating systems work? +

AlphaCode supports Windows, macOS and Linux. Installation instructions and platform-specific options are in the install guide.

How do I keep control of changes? +

Review proposed edits, diffs, test output and risky actions. As with any agent that can execute tools, use appropriate permissions and keep backups of important work.
