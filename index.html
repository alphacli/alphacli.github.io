$ man alphacode | grep -A2 FAQ

          
Questions, answered.

        


        

          Is AlphaCode really free? Do I need an API key?
          
Yes. AlphaCode is MIT-licensed and ships with a free, built-in AI model provider that works immediately after install — no API key, account, or payment required to start. Connect your own Claude, GPT, Gemini, or other provider key later if you want to, but it's never required.

        

        

          Does it send my code anywhere?
          
Only to the model provider that's active — the free built-in lane, or one you configure. The CLI itself is local. Nothing leaves your machine unless a model call needs context.

        

        

          Which models work?
          
The free built-in provider works out of the box. Beyond that, any OpenAI-compatible HTTP endpoint — tested with Claude (Anthropic), GPT-4o/5 (OpenAI), Gemini, Copilot, Cursor, Bedrock, and OpenRouter.

        

        

          How does swarm mode work?
          
A planner turns your goal into a task DAG. Workers — each with their own model — execute independent nodes in parallel. A reviewer node merges and verifies the diff.

        

        

          Can I use it on a remote box with no GUI?
          
Yes. Pure terminal. Pipe-friendly. Plays well with tmux, screen, and SSH.

        

        

          How is this different from Claude Code or Codex CLI?
          
It's MIT, includes a free model so you can start with zero setup, is model-agnostic across 54 providers, swarm-capable, and Rust-fast — using roughly 3–14x less memory than Claude Code, Codex CLI, Cursor Agent, and other terminal agents.
