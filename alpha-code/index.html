AlphaCode / Alpha Code

Alpha Code: the free AI coding agent for your terminal.

AlphaCode (also searched as alpha code, alpha codes or alpha coder) is an open-source AI coding console written in Rust. Describe what you want in plain English; it reads your project, edits files and runs your tests. No API key, no signup.

Install Alpha Code free Read the docs

Why developers pick Alpha Code

Free from the first command

A built-in AI provider is pre-configured. Add Claude, GPT, Gemini or local Ollama later.

Does the work, not just chat

Plans, edits files, runs tests and self-reviews before it says it is done.

Fast and lean

A single Rust binary for Windows, macOS and Linux. Works over SSH and tmux.

You stay in control

Review every diff and approve risky actions. Sessions resume after a crash.
