What is an AI coding agent?

An AI coding agent is software that uses an AI model together with developer tools. It can inspect source code, reason about a request, make edits and run relevant commands or tests. Unlike autocomplete, which predicts text as you type, an agent can work through multiple steps toward an outcome.

Autocomplete versus an agent

CAPABILITYAUTOCOMPLETECODING AGENT
Suggest a line of codeTypically yesYes
Inspect multiple filesLimited or context-dependentOften possible
Apply multi-file editsNot the core workflowCommon workflow
Run tests and review resultsUsually externalPossible with tools
Automate a browserUsually notPossible with integrations

Actual capabilities vary by product and configuration; no agent replaces developer review.

Where it helps

  • Investigate why a test is failing and propose a fix.
  • Refactor duplicated code across a repository.
  • Create tests for a component or endpoint.
  • Explain an unfamiliar codebase and its dependencies.
  • Automate browser checks with appropriate permissions.
