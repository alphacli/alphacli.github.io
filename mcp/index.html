What is MCP?

Model Context Protocol (MCP) is a common interface that lets compatible AI clients connect to external tools and data sources through MCP servers. AlphaCode supports MCP as one of its extensibility mechanisms.

AlphaCode is the client. An MCP server provides the tools or resources. Always use a compatible and trusted server, and follow the active release's configuration guide.

The connection flow

01

Pick the capability

Identify a real task: repository operations, data lookup or a local service.

02

Install a trusted server

Read its documentation, dependencies, permissions and transport requirements.

03

Configure AlphaCode

Follow the current repository's MCP instructions and validate the connection.

04

Review tool activity

Grant only needed access and inspect calls and results.

Security by design

MCP servers can expose powerful capabilities. Treat them like applications with privileges, not as harmless documentation. Use minimal permissions, keep secrets in appropriate credential stores, and avoid exposing untrusted tools to production resources.

Never copy unknown server setup commands into your terminal without reviewing what they install or execute.

Current configuration

The exact MCP configuration format and available tools may change. Instead of presenting potentially stale or fabricated JSON keys here, use the current upstream MCP documentation for the release you have installed.
