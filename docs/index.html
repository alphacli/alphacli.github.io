The essentials

First task

Start in a project directory so AlphaCode has the right context. On Windows, use PowerShell or Windows Terminal. Then run:

alphacode --version
alphacode doctor
alphacode

Describe a small, observable outcome, such as “Find the failing test in this module and fix the cause. Run the relevant tests, then explain what changed.” Review the output and diff before accepting changes.

New to AI coding agents? Ask for an explanation and a plan before edits. Give the agent a well-scoped task with a clear test for success.

How it works

  1. Understand: gather relevant files, dependencies, errors and constraints.
  2. Plan: break the request into actions appropriate for the scope.
  3. Act: edit code, run terminal tools, interact with supported apps, or delegate work.
  4. Verify: inspect test output, changes, and remaining limitations.

Automation can make mistakes. Apply normal software-engineering safeguards: commit frequently, review changed files, and be careful with secrets and destructive commands.

Useful commands

COMMANDPURPOSE
alphacodeLaunch the terminal interface in the current project.
alphacode doctorDiagnose setup and environment.
alphacode --versionPrint the installed version.
alphacode updateCheck and apply supported updates.
alphacode --resumeResume the latest session.
alphacode --guiOpen the Windows desktop interface.

For exhaustive flags and version-specific behavior, consult the official command reference.

Models and providers

AlphaCode includes a free AI provider so you can begin without entering an API key. It also supports other services, including Claude, GPT, Gemini, DeepSeek, Ollama, LM Studio, and compatible endpoints. Availability and setup can change between releases.

Browser, desktop and MCP

AlphaCode goes beyond text editing when the needed tools are connected. Supported workflows include Firefox browser automation, native desktop interactions, and integrations using the Model Context Protocol (MCP).

Use tools only in environments and accounts you control or are authorized to test. Verify important results independently.
