The open-source AI coding agent that lives in your terminal.

AlphaCode is a free, open-source tool written in Rust. Describe what you want in plain English: it reads your project, edits files and runs your tests. No API key, no signup.

Why developers pick AlphaCode

Free from the first command

A built-in AI provider is ready. Add Claude, GPT, Gemini or local Ollama whenever you like.

Does the work, not just chat

Plans, edits files, runs tests and reviews itself before it says it is done.

Fast and lean

One Rust binary for Windows, macOS and Linux. Works over SSH and tmux.

You stay in control

Review every diff and approve risky actions. Sessions resume after a crash.

Install in one line

No step asks for a key. The free provider is ready the moment install finishes.

bash
$ curl -fsSL https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.sh | bash
PS> iwr -useb https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.ps1 | iex
$ git clone https://github.com/dragonked2/alphacode.git && cd alphacode && cargo build --release

Then verify:

  1. which alphacode
  2. alphacode --version
  3. alphacode doctor
  4. alphacode

Frequently asked questions

What is AlphaCode?

AlphaCode (also written Alpha Code) is a free, open-source AI coding agent written in Rust that runs in your terminal. It reads your project, edits files and runs tests.

Do I need an API key or to pay?

No. The free AI provider is configured automatically after install. Later you can use Claude, GPT, Gemini or a local model through Ollama.

Is it the same as the Alpha Coders wallpaper site?

No. Alpha Coders and Wallpaper Abyss is an unrelated wallpaper website. AlphaCode is a developer tool and is not affiliated with it.

Looking for something else? AlphaCode is unrelated to the Alpha Coders wallpaper site, DeepMind's AlphaCode research project and the NATO phonetic alphabet (Alpha, Bravo, Charlie).
