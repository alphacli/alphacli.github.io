De open-source AI-codeeragent die in je terminal woont.

AlphaCode is een gratis, open-source tool geschreven in Rust. Beschrijf in gewone taal wat je wilt: het leest je project, bewerkt bestanden en voert je tests uit. Geen API-sleutel, geen account.

Installeer AlphaCode gratisLees de documentatie

Waarom ontwikkelaars voor AlphaCode kiezen

Gratis vanaf het eerste commando

Een ingebouwde AI-provider staat klaar. Voeg later Claude, GPT, Gemini of lokale Ollama toe.

Doet het werk, niet alleen praten

Plant, bewerkt bestanden, draait tests en controleert zichzelf voordat het klaar meldt.

Snel en licht

Eén Rust-binary voor Windows, macOS en Linux. Werkt via SSH en tmux.

Jij houdt de controle

Bekijk elke wijziging en keur risicovolle acties goed. Sessies hervatten na een crash.

Installeren in één regel

Geen enkele stap vraagt om een sleutel. De gratis provider werkt direct na de installatie.

bash
$ curl -fsSL https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.sh | bash
PS> iwr -useb https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.ps1 | iex
$ git clone https://github.com/dragonked2/alphacode.git && cd alphacode && cargo build --release

Controleer daarna:

  1. which alphacode
  2. alphacode --version
  3. alphacode doctor
  4. alphacode

Veelgestelde vragen

Wat is AlphaCode?

AlphaCode (ook geschreven als Alpha Code) is een gratis, open-source AI-codeeragent in Rust die in je terminal draait. Hij leest je project, bewerkt bestanden en draait tests.

Heb ik een API-sleutel of betaling nodig?

Nee. De gratis AI-provider wordt na installatie automatisch ingesteld. Later kun je Claude, GPT, Gemini of een lokaal model via Ollama gebruiken.

Is AlphaCode hetzelfde als de wallpapersite Alpha Coders?

Nee. Alpha Coders en Wallpaper Abyss is een niet-gerelateerde wallpapersite. AlphaCode is een ontwikkelaarstool en niet aan die site verbonden.

Zoek je iets anders? AlphaCode heeft niets te maken met de wallpapersite Alpha Coders, het onderzoeksproject AlphaCode van DeepMind of het NAVO-spellingalfabet (Alfa, Bravo, Charlie).
