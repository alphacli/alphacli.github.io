AlphaCode / About

Terminal-native AI, built in the open.

AlphaCode is a free, open-source AI coding agent written in Rust. It reads your codebase, edits files, runs tests, automates Firefox and controls desktop apps, with a built-in free model so you can start without an API key.

What AlphaCode is

Free by default

A built-in AI provider is pre-configured. No account, card or API key to start.

Open source (MIT)

Read it, fork it, ship it. Source lives on GitHub and contributions are welcome.

Rust-fast

A lean single binary for Windows, macOS and Linux that works over SSH, tmux and CI.

Model-agnostic

Claude, GPT, Gemini, DeepSeek, Ollama and any OpenAI-compatible endpoint.

Agentic tooling

40+ built-in tools, swarm mode for parallel agents, and MCP server support.

Safety first

Prompts before risky actions and resumable sessions so you stay in control.
