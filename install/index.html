Where are you building?

Select your operating system. We'll show the matching command.

02 / RUN THIS COMMANDTerminal / shell

Open your Terminal app and paste:

curl -fsSL https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.sh | bash
Good to know: The installer downloads a release, verifies its SHA-256 checksum, and installs under ~/.local/bin by default.

Open PowerShell or Windows Terminal (not Command Prompt) and paste:

irm https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.ps1 | iex
Good to know: The installer verifies a SHA-256 checksum, uses a user-level installation path, and does not require administrator rights by default.

Have the appropriate Rust toolchain and a C toolchain installed. Then:

git clone https://github.com/dragonked2/alphacode.git
cd alphacode
cargo build --release
./target/release/alphacode --version
Good to know: Building from source may require extra dependencies. Refer to the upstream installation options.
03 / VERIFY

Make sure everything works.

In the same terminal, run these commands one by one:

alphacode --version
alphacode doctor
alphacode

Run alphacode inside a project folder and describe your first task. On Windows, alphacode --gui can open the desktop interface.

04 / MORE CONTROL

Prefer to choose how it's installed?

The upstream installers support version pinning and PATH options. When passing Windows parameters, load the installer as a PowerShell script block rather than using | iex.

Pin a version

Install a specific tagged release rather than the latest.

--version vX.Y.Z -Version vX.Y.Z

Keep PATH untouched

Useful for custom environments and managed machines.

--no-path -NoPath

Inspect before running

05 / SUPPORT

Something not quite right?

Command not found after installing +

Open a new terminal and try alphacode --version. Check that your user PATH includes the installer location. Run alphacode doctor if the executable is available.

Using Windows Command Prompt (CMD)? +

The Windows install command is PowerShell syntax. Open PowerShell or Windows Terminal rather than CMD.

Want a local AI model? +

Start with the included free provider, or configure Ollama and other compatible models through the project documentation.

Still having trouble? +

Read the current troubleshooting guide or open an issue with your OS, version, and redacted diagnostics.
