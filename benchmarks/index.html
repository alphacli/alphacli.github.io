02 / METHODOLOGY

Measure twice.
Claim once.

The original records contain memory values but not sufficient testing detail to prove equivalent workloads. Treat this page as a transparent archive, not a current ranking.

01

Know the environment

Record OS version, CPU, RAM, architectures and the exact build of every tool being tested.

02

Normalize the workload

Match task, workspace, provider, session count, warm-up and idle/active state across tools.

03

Document the method

Publish sampling duration, resident-memory measurement, repetitions and statistical spread.

04

Reproduce the results

Retest against current software versions. Do not infer code quality, accuracy or task speed from RAM alone.
