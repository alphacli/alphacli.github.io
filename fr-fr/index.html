Comment fonctionne l'agent de code IA


Unlike a chat window or autocomplete, an AI coding agent acts on your project. AlphaCode follows a simple loop and stops to ask before risky actions.






01
Décrivez le résultat
Open your project, run alphacode and say what you want in plain English, such as "fix the failing login test".


02
L'IA planifie et modifie
The language model reads the relevant files, plans the steps, uses its tools to edit code and runs your tests to check the result.


03
Vous relisez et gardez la main
Check the diff, accept or reject changes, and resume any session later with alphacode --resume.

Que peut faire un agent de code IA dans votre terminal ?


AlphaCode is an agentic CLI: you describe an outcome, it reads your repository, makes the edits, runs your tests, and reports back. Here are the jobs developers use it for most.






Fix bugs and failing tests
Point AlphaCode at a failing test suite. It reproduces the error, finds the cause with regex and AST search, patches the code and re-runs the tests until they pass.


Refactor and migrate code
Rename APIs, upgrade frameworks or move an auth system to OAuth 2.1. Swarm mode splits large migrations into parallel tasks and merges the reviewed result.


Automate Firefox and the desktop
Drive a real browser for end-to-end checks, scrape documentation, or operate desktop apps from the same terminal session you use for coding.


Connect tools through MCP
Register Model Context Protocol servers to give the agent new tools, such as security scanners or internal APIs. See the MCP guide.


Work on any server over SSH
AlphaCode is a single Rust binary with no GUI requirement, so it runs inside tmux, screen, CI runners and remote boxes just as well as on a laptop.


Choose your own model
Start on the built-in free provider, then switch to Claude, GPT, Gemini, DeepSeek, Mistral, Ollama or any OpenAI-compatible endpoint without reinstalling.

FAQ de l'agent de code IA : vos questions, nos réponses.




Faut-il une clé API ou payer ?
Non. Le fournisseur d'IA gratuit est configuré automatiquement après l'installation. Vous pourrez ensuite utiliser Claude, GPT, Gemini ou un modèle local via Ollama.


Does AlphaCode send code to a model provider?
AlphaCode runs on your machine, but it may send task context to the active model provider to generate responses. Which data is sent depends on the task, tools used, and provider configuration. Review provider privacy terms and avoid including secrets in prompts or files shared with a model.


Which models and providers work?
The built-in free provider works out of the box. AlphaCode also supports a range of third-party integrations and OpenAI-compatible endpoints. The available providers may change by release; check the documentation for current setup details.


Qu'est-ce qu'AlphaCode ?
AlphaCode (aussi écrit Alpha Code) est un agent de code IA gratuit et open source, écrit en Rust, qui s'exécute dans votre terminal. Il lit votre projet, modifie les fichiers et lance les tests.


AlphaCode est-il le même que le site de fonds d'écran Alpha Coders ?
Non. Alpha Coders et Wallpaper Abyss est un site de fonds d'écran indépendant. AlphaCode est un outil pour développeurs, sans lien avec lui.


How does swarm mode work?
A planner turns your goal into a task DAG. Workers — each with their own model — execute independent nodes in parallel. A reviewer node merges and verifies the diff.


Can I use it on a remote box with no GUI?
Yes. Pure terminal. Pipe-friendly. Plays well with tmux, screen, and SSH.


How is AlphaCode different from other coding agents?
AlphaCode is MIT-licensed, includes a built-in free AI provider, supports multiple model providers, offers swarm workflows, and is written in Rust. The benchmark section provides historical memory measurements for specific test conditions; results vary by version, configuration, and workload.


What is an AI coding agent?
An AI coding agent is software that uses a large language model to complete programming tasks on your behalf. It reads your codebase, plans the work, edits files, runs commands and tests, and reports back, instead of only suggesting the next line. AlphaCode is a free, open-source AI coding agent that runs in your terminal.


Is AlphaCode an alternative to Claude Code, Cursor or GitHub Copilot?
AlphaCode is an open-source, terminal-based AI coding agent in the same category. It is MIT-licensed, written in Rust, includes a free built-in AI provider and can also connect to Claude, GPT, Gemini and other providers you already use. Compare features and privacy terms for your own workflow.


Can AlphaCode use local LLMs such as Ollama or LM Studio?
Yes. Ollama and LM Studio are listed among the supported providers, and any OpenAI-compatible endpoint can be used by setting its api_base. This lets you run an AI coding agent against a model on your own machine.
