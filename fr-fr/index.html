L'agent de code IA open source qui vit dans votre terminal.

AlphaCode est un outil gratuit et open source écrit en Rust. Décrivez ce que vous voulez en langage naturel : il lit votre projet, modifie les fichiers et exécute vos tests. Sans clé API ni inscription.

Installer AlphaCode gratuitementLire la documentation

Pourquoi les développeurs choisissent AlphaCode

Gratuit dès la première commande

Un fournisseur d'IA intégré est prêt. Ajoutez Claude, GPT, Gemini ou Ollama en local plus tard.

Il agit, il ne fait pas que discuter

Il planifie, modifie les fichiers, lance les tests et se relit avant de conclure.

Rapide et léger

Un seul binaire Rust pour Windows, macOS et Linux. Fonctionne via SSH et tmux.

Vous gardez la main

Relisez chaque modification et validez les actions sensibles. Les sessions reprennent après un plantage.

Installation en une ligne

Aucune étape ne demande de clé. Le fournisseur gratuit est prêt dès la fin de l'installation.

bash
$ curl -fsSL https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.sh | bash
PS> iwr -useb https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.ps1 | iex
$ git clone https://github.com/dragonked2/alphacode.git && cd alphacode && cargo build --release

Vérifiez ensuite :

  1. which alphacode
  2. alphacode --version
  3. alphacode doctor
  4. alphacode

Questions fréquentes

Qu'est-ce qu'AlphaCode ?

AlphaCode (aussi écrit Alpha Code) est un agent de code IA gratuit et open source, écrit en Rust, qui s'exécute dans votre terminal. Il lit votre projet, modifie les fichiers et lance les tests.

Faut-il une clé API ou payer ?

Non. Le fournisseur d'IA gratuit est configuré automatiquement après l'installation. Vous pourrez ensuite utiliser Claude, GPT, Gemini ou un modèle local via Ollama.

AlphaCode est-il le même que le site de fonds d'écran Alpha Coders ?

Non. Alpha Coders et Wallpaper Abyss est un site de fonds d'écran indépendant. AlphaCode est un outil pour développeurs, sans lien avec lui.

Vous cherchez autre chose ? AlphaCode n'a aucun rapport avec le site de fonds d'écran Alpha Coders, le projet de recherche AlphaCode de DeepMind ni l'alphabet phonétique de l'OTAN (Alpha, Bravo, Charlie).
