وكيل البرمجة بالذكاء الاصطناعي الذي يعيش في الطرفية.

AlphaCode أداة مجانية ومفتوحة المصدر مكتوبة بلغة Rust. صِف ما تريده بلغتك العادية، فيقرأ مشروعك ويعدّل الملفات ويشغّل الاختبارات. بلا مفتاح API وبلا تسجيل.

ثبّت AlphaCode مجانًااقرأ التوثيق

لماذا يختاره المطوّرون

مجاني من أول أمر

مزوّد ذكاء اصطناعي مدمج وجاهز. أضف Claude أو GPT أو Gemini أو Ollama المحلي لاحقًا وقتما شئت.

ينفّذ العمل ولا يكتفي بالحوار

يخطّط ويعدّل الملفات ويشغّل الاختبارات ويراجع نفسه قبل أن يعلن الانتهاء.

سريع وخفيف

ملف تنفيذي واحد بلغة Rust لأنظمة Windows وmacOS وLinux، ويعمل عبر SSH وtmux.

التحكم بيدك

راجع كل تعديل ووافق على الإجراءات الحسّاسة. والجلسات تُستأنف بعد أي انقطاع.

التثبيت بسطر واحد

لا تطلب أي خطوة مفتاحًا. المزوّد المجاني يعمل فور انتهاء التثبيت.

bash
$ curl -fsSL https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.sh | bash
PS> iwr -useb https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.ps1 | iex
$ git clone https://github.com/dragonked2/alphacode.git && cd alphacode && cargo build --release

ثم تحقّق:

  1. which alphacode
  2. alphacode --version
  3. alphacode doctor
  4. alphacode

أسئلة شائعة

ما هو AlphaCode؟

AlphaCode (ويُكتب أيضًا Alpha Code) وكيل برمجة بالذكاء الاصطناعي مجاني ومفتوح المصدر، مكتوب بلغة Rust ويعمل في الطرفية. يقرأ مشروعك ويعدّل الملفات ويشغّل الاختبارات.

هل يحتاج إلى مفتاح API أو دفع؟

لا. مزوّد الذكاء الاصطناعي المجاني يُضبط تلقائيًا بعد التثبيت. ويمكنك لاحقًا استخدام Claude أو GPT أو Gemini أو نموذج محلي عبر Ollama.

هل هو نفسه موقع Alpha Coders للخلفيات؟

لا. موقع Alpha Coders وWallpaper Abyss موقع خلفيات مستقل لا علاقة له بنا. AlphaCode أداة للمطوّرين وليست مرتبطة به.

تبحث عن شيء آخر؟ AlphaCode لا علاقة له بموقع Alpha Coders للخلفيات ولا بمشروع AlphaCode البحثي من DeepMind ولا بالأبجدية الصوتية العسكرية (ألفا، براڤو، تشارلي).
