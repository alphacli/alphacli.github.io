El agente de programación con IA de código abierto que vive en tu terminal.

AlphaCode es una herramienta gratuita y de código abierto escrita en Rust. Describe lo que quieres en lenguaje normal: lee tu proyecto, edita archivos y ejecuta tus pruebas. Sin clave de API ni registro.

Por qué los desarrolladores eligen AlphaCode

Gratis desde el primer comando

Ya incluye un proveedor de IA listo para usar. Añade Claude, GPT, Gemini u Ollama local cuando quieras.

Hace el trabajo, no solo conversa

Planifica, edita archivos, ejecuta pruebas y se revisa antes de decir que terminó.

Rápido y ligero

Un único binario de Rust para Windows, macOS y Linux. Funciona por SSH y tmux.

Tú tienes el control

Revisa cada cambio y aprueba las acciones delicadas. Las sesiones se reanudan tras un fallo.

Instalación en una línea

Ningún paso pide una clave. El proveedor gratuito está listo en cuanto termina la instalación.

bash
$ curl -fsSL https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.sh | bash
PS> iwr -useb https://raw.githubusercontent.com/dragonked2/alphacode/main/scripts/install.ps1 | iex
$ git clone https://github.com/dragonked2/alphacode.git && cd alphacode && cargo build --release

Después, verifica:

  1. which alphacode
  2. alphacode --version
  3. alphacode doctor
  4. alphacode

Preguntas frecuentes

¿Qué es AlphaCode?

AlphaCode (también escrito Alpha Code) es un agente de programación con IA gratuito y de código abierto, escrito en Rust, que se ejecuta en tu terminal. Lee tu proyecto, edita archivos y ejecuta pruebas.

¿Necesito una clave de API o pagar?

No. El proveedor de IA gratuito se configura solo tras la instalación. Más adelante puedes usar Claude, GPT, Gemini o un modelo local con Ollama.

¿Es lo mismo que el sitio de fondos de pantalla Alpha Coders?

No. Alpha Coders y Wallpaper Abyss es un sitio de fondos de pantalla independiente. AlphaCode es una herramienta para desarrolladores y no está vinculada a él.

¿Buscas otra cosa? AlphaCode no tiene relación con el sitio de fondos de pantalla Alpha Coders, con el proyecto de investigación AlphaCode de DeepMind ni con el alfabeto fonético de la OTAN (Alfa, Bravo, Charlie).
